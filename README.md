# Word Goal for Minimide

Shows the words in the current file next to your goal, like `✍️ 120 / 500`, and
celebrates when you reach it. Click it to change the goal.

Install in Minimide with **Packages: Install Package…** → `mikemich/minimide-word-goal`,
or find it in **Settings → Packages → Discover**. It runs sandboxed and asks for no
permissions.
